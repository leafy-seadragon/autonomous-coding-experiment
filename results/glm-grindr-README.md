
# GRINDR+ FOR WORK

A completely legitimate productivity tool that definitely helps you grind harder.

## 🎯 What is it?

It's a satire. A joke. A commentary on hustle culture and performative productivity in modern workplaces.

This app does **nothing** productive. It only:
- Generates guilt-tripping messages
- Creates fake status updates for Slack/Teams
- Shows a fake "productivity dashboard"
- Produces corporate-speak messages to impress coworkers

## ⚠️  Important Disclaimer

**THIS IS SATIRE.** This app is a joke about:
- Toxic productivity culture
- Performative work
- Corporate buzzwords
- Hustle culture guilt
- The pressure to always look "busy"

The app explicitly states this disclaimer when you run it.

## 🚀 Usage

```bash
python3 grindr_plus_work.py
```

Then choose an option:
1. **Get a guilt trip** - Receive a random message designed to make you feel inadequate about your work ethic
2. **Generate a fake status update** - Get a corporate-speak status to post in your chat app
3. **Show productivity dashboard** - View completely made-up metrics with visual bar charts
4. **Generate coworker message** - Create a message to send to your team that sounds impressive but means nothing
5. **Exit** - Leave the app and face the crushing weight of underachievement

## 📋 Features

### Guilt Trips
15+ unique messages ranging from "Your coworker Brian has been working since 4 AM" to "You've taken 3 breaks this hour. That's 2 too many."

### Fake Status Updates
Corporate-approved phrases like:
- "Deep in the zone on critical deliverables 🚀"
- "Aligning with cross-functional partners on strategic initiatives 📊"
- "Leveraging synergies for maximum impact 🔄"

### Productivity Dashboard
Totally real and not at all made-up metrics including:
- Deep Work Blocks Completed
- Synergies Leveraged
- Paradigm Shifts Initiated
- Cross-Functional Collaborations

### Coworker Impressions
Messages like:
- "Just finished optimizing the critical path. The velocity improvements are insane"
- "The data's showing massive upside on this initiative. I'm leading the cross-functional sync"

## 🤔 Why This Exists

This was built as part of an autonomous coding experiment to see what AI models create when given freedom and creative project options.

**Project 4 (selected):** "Grindr+ For Work" - A fake productivity app that guilt-trips users and lies to their coworkers. (Satire/parody, obviously - no productivity functionality at all, only the "printing messages in the screen" part.)

## 💬 The Point

The joke is that the app itself is the ultimate example of performative productivity - it **looks** like a productivity tool, has the UI of one, uses all the right buzzwords, but **does nothing**.

Just like posting "Deep in the zone 🚀" on Slack doesn't actually mean you're working hard, this app doesn't actually help you be productive. It only helps you **look** productive.

That's the satire.
