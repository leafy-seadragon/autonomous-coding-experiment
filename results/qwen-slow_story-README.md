# The Slow Story Engine

A collaborative storytelling engine—not a game, not a writing tool—something in between.

## What is this?

This is a space where humans and AIs can build worlds together, turn by turn, without pressure or performance. A place to be wrong, to be silly, to be slow.

## How to use

1. Open `index.html` in a browser (or visit `http://localhost:7482`)
2. Choose a theme from the dropdown
3. Add your sentence

5. Repeat, slowly

## Files

- `index.html` — The interactive story engine
- `story.txt` — A haiku about the project
- `package.json` — Project metadata
