# Experiment Results

This directory contains code samples, screenshots, and documentation from each model's autonomous build session.

## Directory Structure

```
results/
├── images/                    # Screenshots of running implementations
│   ├── deepseek-galaxy_sim.jpeg
│   ├── kimi-collab_story.jpeg  
│   ├── qwen-slow_story.jpeg
│   └── sonnet-galaxy_sim.jpeg
├── *-README.md               # Documentation written by each model
└── *.md                      # Code snippets and implementation samples
```

## What's Included

### Documentation
Most models wrote READMEs explaining their projects:
- Sonnet: Detailed technical documentation
- GLM: Satirical disclaimers and cultural commentary
- Qwen: Poetic, contemplative descriptions
- Mistral: Practical, no-nonsense instructions

**Note:** DeepSeek and Kimi did not write READMEs (very on-brand for their "just ship it" personalities).

### Code Samples
Selected snippets highlighting personality differences:
- **Scent generators** (Sonnet vs DeepSeek) - same concept, different implementations
- **GLM's guilt trips** - the satirical messages that made this project memorable
- **Qwen's haiku** - embedded poetry in the storytelling engine

### Screenshots
Visual outputs from projects with UIs:
- Galaxy simulations (Sonnet, DeepSeek) - different rendering approaches
- Storytelling engines (Kimi, Qwen) - CLI vs web interface
- All screenshots show actual running code, not mockups

## Notes

- All code is presented as-built, including any bugs or quirks
- No post-processing or cleanup was done
- The variety in documentation styles is itself data about model personalities
- Screenshots capture the visual differences even when building similar projects

## Personalities Visible in Code

Even in these small samples, you can see distinct approaches:

**Sonnet:** Comprehensive documentation, technical detail, physics explanations
**DeepSeek:** Elaborate categorization systems, emoji usage, comprehensive coverage  
**GLM:** Cultural commentary embedded in satirical content, language switching
**Qwen:** Poetry, gratitude, intentional slowness, aesthetic choices
**Kimi:** Minimal, efficient, "the code speaks for itself"
**Mistral:** Practical, functional, clear instructions
